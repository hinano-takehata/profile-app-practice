# profile-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。
コントローラー内で準備した固定データを使い、コントローラー→ルーティング→ビューの連携を実践したもの。

## 使用技術
- PHP 8.2
- Laravel 10.3.3
- Blade テンプレート


## 学んだこと
- Laravel の「ルーティング → コントローラー → ビュー」の基本的な流れの作り方
- 自分が作ったコントローラー名が間違っていたので、一度自己紹介ページにならなかったが、その間違えたコントローラー名を
　入力するところを一つ一つ手直しすることで、よりコントローラー、ルーティング、ビューのつながりを意識した。
- コントローラーからビューへのデータの受け渡し方を学んだ。

## 動作確認
http://localhost/profile
にアクセスし、自己紹介ページが表示されたことを確認した。
